把想法写成曲线

公式本身可以直接点击编辑，输入时立即排版。点击下面的例子，会把它添加到表达式列表。

ƒ

键盘会自动出现。把光标放进任意公式，页面底部就会展开全宽数学键盘；点击空白处或按 Esc 收起。主键盘提供方向键和回车。「ABC/αβγ」中的 αβγ 键可切换到希腊字母。

∞

输入规则：函数可省略括号，例如 sin x；复合参数请写 sin(2x)。若写 sin 2x，会按 (sin 2)·x 解析。乘号可省略：2x、ab、x2；变量可以是单字母或下标形式，如 a、a_1。输入 int、sum、prod、inf 会自动变成对应符号；输入 pi、theta、alpha、Gamma 等希腊字母拼写会立即变成 \pi、\theta 等 LaTeX 命令，在空格、括号和运算符前后都有效。

∫

微积分与结果：在“函数与微积分”中插入导数、积分、求和或连乘。积分、求和和连乘的上下限可直接填写。常数结果显示在表达式卡片里。连续点击“导数”可求高阶导数。

f

函数名与结果：只有自变量只有 x 的裸表达式才自动补成 f(x)=…、g(x)=…；y=… 保持原样，x=… 视为隐函数，a=… 视为赋值/滑块。函数名可以写进后续公式，例如 f(2x)、f(t)、f(g(x))。常数表达式只显示结果、不画图；y=2 是常函数并画水平线，f(x)=2 也画水平线。

变量与滑块

用单个字母或带下标的字母定义变量，例如 a = 1.5、a_1 = 2。表达式卡片会变成滑块，拖动即可实时更新所有引用它的曲线。

输入 y = mx+b 后，可一键为未定义的变量添加滑块。

键盘里的 a_b 插入下标，a^b 插入上标。

参数曲线和极坐标的范围也支持自动替换，例如输入 3pi 会显示为 3π。

画布手势

拖拽平移，滚轮或双指缩放。点击画布工具栏上的复位按钮可回到初始视图。鼠标悬停时左下角会显示坐标。

点击曲线选择图像，点击其他曲线可切换。再点已选曲线或点击空白处可取消选择。移动鼠标或在触屏上拖动可追踪选中的图像。圆点标示交点和显函数的局部极值。

使用顶部“视图设置”可以切换网格、坐标轴与三角函数角度单位。

{ }

限制条件。在直角坐标曲线或不等式末尾加花括号，例如 y = x² {0 < x < 2}。
